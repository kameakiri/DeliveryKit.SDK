# FAQ

## Q. DeliveryKit.ApiTemplate は公開する必要がありますか？
A. いいえ。SDK の利用例として samples に置くのは OK ですが、  
   API 本体は公開対象ではありません。

## Q. ログは削除されますか？
A. 削除されません。180日後に LogsArchive へ移動されます。

## Q. SDK のモデルを API 側で再定義する必要はありますか？
A. ありません。API は SDK のモデルをそのまま利用します。

## Q. AI パイプラインは必須ですか？
A. 任意です。ログを AI 学習に使う場合のみ利用します。
